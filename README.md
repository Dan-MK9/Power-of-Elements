# Power of Elements - SENAI Game Dev Challenge

Projeto desenvolvido como parte de uma dinâmica prática no curso técnico de Programação de Jogos Digitais do SENAI. O objetivo foi criar uma fase jogável no estilo plataforma 3D, utilizando a Unity, com foco em implementar diversas mecânicas solicitadas em uma cartela de bingo de desenvolvimento de jogos.

## 🎮 Sobre o Jogo

Neste jogo de plataforma 3D, o jogador deve explorar um cenário natural (Low Poly) repleto de obstáculos e coletar todos os cristais mágicos espalhados pelo ambiente para completar a fase. Elementos da natureza atuam como desafios com comportamentos e efeitos próprios.

## 💧 Elementos Implementados

- **Elemento principal: Água**
  - Dano inicial: **1 ponto de vida**
  - Dano contínuo: se permanecer na água por mais de 3 segundos, sofre **1 ponto de dano adicional**
  - Efeito: **lentidão nos movimentos**
  
- **Elemento adicional: Fogo**
  - Dano inicial: **1 ponto de vida**
  - Dano contínuo: ao sair da área de fogo, sofre **0.5 de dano ao longo de 1,5 segundos**

## ✅ Requisitos Atendidos (Bingo SENAI)

- ✅ Sistema de movimentação do player (com pulo)
- ✅ Sistema de vida com 3 corações
- ✅ Sistema de colisão com obstáculos e cenário
- ✅ Sistema de dano com variações por elemento
- ✅ Sistema de coleta de cristais
- ✅ Upgrade de velocidade
- ✅ Upgrade de pulo (pulo duplo)
- ✅ Upgrade de invencibilidade
- ✅ Sistema de ataque do player
- ✅ Adição de pelo menos um inimigo
- ✅ Comportamento específico dos obstáculos
- ✅ Inclusão de obstáculo adicional (Fogo)
- ✅ Manipulação/adaptação de assets do cenário
- ✅ Trilha sonora
- ✅ Mecânica extra fora do escopo

## 🧪 Outros Destaques

- Interface com barra de vida em formato de **corações**
- **Tela pisca em vermelho** ao sofrer dano
- Tela de **Game Over com botão de restart**
- Contador de cristais coletados exibido no HUD
- Feedbacks visuais e sonoros ao interagir com inimigos e itens
- Elementos com comportamentos únicos e efeitos visuais distintos

## 🛠️ Tecnologias Utilizadas

- Unity
- C# com componentes nativos da Unity
- Assets fornecidos pelo SENAI e complementares pesquisados

## 📌 Objetivo do Projeto

- Praticar lógica de programação aplicada a jogos
- Desenvolver e integrar múltiplos sistemas de gameplay e UI
- Explorar efeitos visuais e sonoros para imersão do jogador
